## Project Description

The DevOps Capstone Project focuses on developing a Customer Accounts microservice for an e-commerce application.

## Project Name

**DevOps Capstone**

## Objectives

- Develop and test a RESTful microservice.
- Use GitHub for version control.
- Automate build checks using GitHub Actions.
- Apply continuous integration and continuous delivery practices.
- Test and deploy the application using DevOps tools.

## Technologies Used

- Python
- Flask
- Git and GitHub
- GitHub Actions
- Docker
- Kubernetes and OpenShift
- Tekton
